# Homely — Real Estate App

Home-search mobile app in an interactive phone frame.

**[Live Demo](https://shaisolaris.github.io/flutter-homely/)**

## Features

- **Listing feed** — five homes with type filters, listing tags, heart favorites with price-drop alerts
- **Detail view** — full specs including price-per-sqft, photography
- **Mortgage calculator** — down-payment and rate sliders producing a live monthly figure with P&I/tax/insurance split
- **Agent contact** — message and tour-request flows
- **Saved tab** — favorited homes rendered as full cards

## Structure

Single self-contained page: Flutter-style mobile patterns in pure HTML/CSS/JS. No frameworks, no build step.
